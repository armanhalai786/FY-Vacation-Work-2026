# FY Vacation Work 2026 — Personal Portfolio Website

A beginner-friendly responsive portfolio website created using HTML, CSS, and JavaScript.

## How to use
1. Open `index.html` in a browser to preview the website.
2. Replace `Your Name`, `YN`, sample email, and profile links with your own details.
3. Update the project cards after you have completed and tested the projects.
4. Upload `index.html` and `README.md` to your GitHub repository.

## Technologies
- HTML
- CSS
- JavaScript

## Features
- Responsive layout for mobile and desktop
- About, Skills, Projects, and Contact sections
- Contact form that prepares an email using the visitor's email application

## Important
The contact form is a front-end demo. It does not send or store messages on a server. Replace `your.email@example.com` in `index.html` with your own email address.
